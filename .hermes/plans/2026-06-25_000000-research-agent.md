# Dran Agents Implementation Plan

> **For Hermes:** Use the `subagent-driven-development` skill to implement this plan task-by-task. This is a concept-level refactor: treat Ingest, Search, and Research as autonomous agents built on a shared ReAct engine.

## Goal

Build three autonomous ReAct agents inside Dran:

- **Research** — explores a topic on the web and creates pages to fill knowledge gaps.
- **Ingest** — ingests URLs or files into the brain, deciding whether to download, convert, and/or enrich.
- **Search** — answers a query by orchestrating semantic search, full-text search, and optional web search.

All agents share a common engine, schema, PubSub topics, and LiveView UI. They are also exposed as MCP tools so other agents (e.g. Hermes) can start them asynchronously and poll for results.

## Architecture

| Layer | Responsibility |
|-------|----------------|
| `Dran.Agent.Session` / `Dran.Agent.Step` | Generic DB tables for any agent run (typed by `agent_type`). |
| `Dran.Agent.Engine` | ReAct loop with tool-calling LLM, DB logging, and PubSub broadcasts. |
| `Dran.Agent.Research` / `Dran.Agent.Ingest` / `Dran.Agent.Search` | Tool schemas + tool execution callbacks for each agent type. |
| `DranWeb.AgentLive` | Single LiveView that renders `/agents/:type` and `/agents/:type/:id`. |
| `Dran.MCP` | Exposes `start_agent` / `get_agent_session` (or typed aliases) so external agents can invoke them. |
| `Mix.Tasks.Dran.Agent` | CLI entry point for headless runs. |

**Tech Stack:** Elixir, Phoenix LiveView, PostgreSQL, Req, `Dran.Inference.chat`, Phoenix.PubSub, Firecrawl.

### Task 3: Base Agent Engine — `Dran.Agent.Engine`

**Objective:** A single ReAct loop that runs any agent by delegating tool execution to a callback module.

**Files:**
- Create `lib/dran/agent/engine.ex`

**Design:**

```elixir
defmodule Dran.Agent.Engine do
  @moduledoc """
  Generic ReAct engine for Dran agents.

  `run(module, input, context_id, opts)` creates a session, then spawns the
  loop on `Dran.Relations.TaskSupervisor`. The supplied `module` must implement:

    - `agent_type/0` → string
    - `tools/0` → list of OpenAI function schemas
    - `system_prompt/0` → string
    - `build_messages(input, session)` → list of messages
    - `execute_tool(tool_name, args, state)` → {result, new_state}
    - `summarize_result(result)` → map (optional, default provided)

  Each step is persisted and broadcasted via `Dran.PubSub` on
  `"agents:#{session_id}"` and `"agents:all"`.
  """

  require Logger
  import Ecto.Query

  alias Dran.{Inference, Repo}
  alias Dran.Agent.{Session, Step}

  @max_steps 15

  def run(module, input, context_id, opts \\ []) do
    session = create_session!(module, input, context_id, opts)

    Task.Supervisor.start_child(Dran.Relations.TaskSupervisor, fn ->
      execute_loop(module, session, opts)
    end)

    {:ok, session}
  end

  defp create_session!(module, input, context_id, opts) do
    {:ok, session} =
      %Session{}
      |> Session.changeset(%{
        agent_type: module.agent_type(),
        input: input,
        context_id: context_id,
        status: "running",
        started_at: DateTime.utc_now() |> DateTime.truncate(:second),
        meta: %{model: Inference.chat_model(), opts: opts}
      })
      |> Repo.insert()

    session
  end

  defp execute_loop(module, %Session{} = session, opts) do
    state = %{
      session: session,
      module: module,
      messages: module.build_messages(session.input, session),
      step: 0,
      pages_created: 0,
      opts: opts
    }

    loop(state)
  end

  defp loop(%{step: step}) when step >= @max_steps do
    Logger.info("Agent.Engine: max steps reached (#{@max_steps})")
    :ok
  end

  defp loop(state) do
    case call_llm(state) do
      {:ok, %{reasoning: reasoning, tool: tool, args: args, assistant_message: assistant_message}} ->
        state = %{state | step: state.step + 1}
        step = log_step!(state, tool, args, reasoning)
        broadcast(state, {:step_started, step})

        {result, state} = state.module.execute_tool(tool, args, state)
        update_step!(step, result, state.module)
        broadcast(state, {:step_completed, step, summarize_result(result, state.module)})

        if tool == "done" do
          finish_session(state, args)
        else
          state = add_to_messages(state, assistant_message, tool, result)
          loop(state)
        end

      {:error, reason} ->
        Logger.warning("Agent.Engine: LLM/tool-call error: #{inspect(reason)}")
        finish_session(state, %{"summary" => "LLM error: #{inspect(reason)}"})
    end
  end

  # ── LLM ──

  defp call_llm(state) do
    payload = %{
      "model" => Inference.chat_model(),
      "messages" => state.messages,
      "tools" => state.module.tools(),
      "tool_choice" => "auto",
      "temperature" => 0.4
    }

    case Inference.chat(payload) do
      {:ok, message} -> extract_tool_call(message)
      {:error, reason} -> {:error, reason}
    end
  end

  defp extract_tool_call(message) do
    case List.first(Map.get(message, "tool_calls", [])) do
      %{"function" => %{"name" => name, "arguments" => args}} when is_binary(args) ->
        case Jason.decode(args) do
          {:ok, decoded} ->
            {:ok, %{
              reasoning: "Tool call requested by LLM",
              tool: name,
              args: decoded,
              assistant_message: message
            }}

          _ ->
            {:error, :invalid_tool_args}
        end

      _ ->
        content = Map.get(message, "content", "")
        parse_response(content)
    end
  end

  defp parse_response(text) do
    text = String.trim(text)

    case extract_json(text) do
      nil ->
        {:error, :no_json}

      json_str ->
        case Jason.decode(json_str) do
          {:ok, decoded} when is_map(decoded) ->
            {:ok, %{
              reasoning: Map.get(decoded, "reasoning", ""),
              tool: Map.get(decoded, "tool", ""),
              args: Map.get(decoded, "args", %{}),
              assistant_message: %{"content" => text}
            }}

          _ ->
            {:error, :invalid_json}
        end
    end
  end

  defp extract_json(text) do
    cond do
      String.contains?(text, "```json") ->
        case Regex.run(~r/```json\s*(.*?)\s*```/s, text) do
          [_, json] -> json
          _ -> nil
        end

      Regex.match?(~r/\{.*\}/s, text) ->
        case Regex.run(~r/\{.*\}/s, text) do
          [json] -> json
          _ -> nil
        end

      true ->
        nil
    end
  end

  # ── DB logging ──

  defp log_step!(state, tool, args, reasoning) do
    {:ok, step} =
      %Step{}
      |> Step.changeset(%{
        session_id: state.session.id,
        step_number: state.step,
        tool_name: tool,
        tool_args: args,
        reasoning: reasoning
      })
      |> Repo.insert()

    Repo.update_all(from(s in Session, where: s.id == ^state.session.id),
      set: [steps_count: state.step])

    step
  end

  defp update_step!(step, result, module) do
    step
    |> Step.changeset(%{tool_result: summarize_result(result, module)})
    |> Repo.update!()
  end

  def summarize_result({:ok, data}, _module) when is_list(data),
    do: %{status: "ok", count: length(data), data: data}
  def summarize_result({:ok, data}, _module) when is_map(data),
    do: %{status: "ok", data: data}
  def summarize_result({:ok, :done}, _module), do: %{status: "done"}
  def summarize_result({:error, reason}, _module), do: %{status: "error", error: inspect(reason)}

  # ── Session lifecycle ──

  defp finish_session(state, args) do
    summary = args["summary"] || "Agent completed"

    Repo.get!(Session, state.session.id)
    |> Session.changeset(%{
      status: "done",
      summary: summary,
      pages_created: state.pages_created,
      completed_at: DateTime.utc_now() |> DateTime.truncate(:second)
    })
    |> Repo.update!()

    broadcast(state, {:session_done, summary, state.pages_created})
  end

  # ── PubSub ──

  defp broadcast(state, message) do
    Phoenix.PubSub.broadcast(Dran.PubSub, "agents:#{state.session.id}", message)
    Phoenix.PubSub.broadcast(Dran.PubSub, "agents:all", {:agent, state.session.id, message})
  end

  # ── Helpers ──

  defp add_to_messages(state, assistant_message, tool, result) do
    tool_result_str = format_tool_result(result, state.module)
    tool_call_id = get_tool_call_id(assistant_message)

    assistant_entry =
      Map.merge(assistant_message, %{
        "role" => "assistant",
        "content" => Map.get(assistant_message, "content", "")
      })

    tool_entry = %{
      "role" => "tool",
      "tool_call_id" => tool_call_id,
      "content" => tool_result_str
    }

    %{state |
      messages: state.messages ++ [assistant_entry, tool_entry]
    }
  end

  defp get_tool_call_id(%{"tool_calls" => [%{"id" => id} | _]}), do: id
  defp get_tool_call_id(_), do: "call_fallback"

  defp format_tool_result(result, module) do
    case summarize_result(result, module) do
      %{data: data} when is_list(data) ->
        Enum.map_join(data, "\n", fn item ->
          "- #{item[:title] || item[:url] || item[:slug] || inspect(item)}"
        end)

      %{data: data} when is_map(data) ->
        Jason.encode!(data) |> String.slice(0, 2000)

      %{status: status} ->
        to_string(status)
    end
  end
end
```

```elixir
defmodule Dran.Agent.Research do
  @moduledoc "Research agent: searches/scrapes the web and creates pages."

  alias Dran.{Brain, Firecrawl}

  @impl Dran.Agent.Engine.Behaviour
  def agent_type, do: "research"

  def tools do
    [
      # web_search, web_scrape, create_page, search_pages, done
      # (same function schemas as in Task 3)
    ]
  end

  def system_prompt do
    """
    You are a research agent for Dran. Research the topic thoroughly.
    - Search the web first.
    - Check existing pages before creating new ones.
    - Create 1-5 concise pages.
    - Cite sources naturally.
    - Call done when finished.
    """
  end

  def build_messages(input, session) do
    [
      %{"role" => "system", "content" => system_prompt()},
      %{"role" => "user", "content" => "Research topic: #{input}\nSession: #{session.id}"}
    ]
  end

  def execute_tool("web_search", args, state) do
    result = Firecrawl.search(args["query"] || "", limit: 5)
    {result, state}
  end

  def execute_tool("web_scrape", args, state) do
    result = Firecrawl.scrape(args["url"] || "")
    {result, state}
  end

  def execute_tool("create_page", args, state) do
    page_attrs = %{
      context_id: state.session.context_id,
      title: args["title"],
      body: args["body"],
      page_type: args["page_type"] || "concept",
      created_by: "research-agent",
      owner: "research-agent",
      meta: %{"agent_session_id" => state.session.id}
    }

    case Brain.create_page(page_attrs) do
      {:ok, page} ->
        Phoenix.PubSub.broadcast(Dran.PubSub, "agents:#{state.session.id}",
          {:page_created, page})
        {{:ok, %{slug: page.slug, id: page.id}},
          %{state | pages_created: state.pages_created + 1}}

      {:error, cs} ->
        {{:error, inspect(cs.errors)}, state}
    end
  end

  def execute_tool("search_pages", args, state) do
    result = Brain.semantic_search(args["query"] || "", context_id: state.session.context_id, limit: 10)
    {result, state}
  end

  def execute_tool("done", _args, state), do: {{:ok, :done}, state}
  def execute_tool(tool, _args, state), do: {{:error, :unknown_tool}, state}
end
```

## Risks / Tradeoffs

1. **LLM tool calling**: Verified — `Qwen3.6-35B-A3B` returns native `tool_calls` with `finish_reason: "tool_calls"`. The engine uses native function calling and falls back to JSON parsing only when needed.

2. **Context window**: Fifteen max steps × ~3-5KB = ~45-75KB per session. If this becomes a problem, reduce `@max_steps` or truncate older messages in `add_to_messages/4`.

3. **Ingesting files asynchronously**: Files uploaded from LiveView must be stored before the agent runs (the agent receives a pointer, not a `Plug.Upload`). Keep upload logic in `AgentLive` and pass `upload_id`/`path` via `opts`.

4. **Backpressure**: No dedicated queue for agents yet. For now `Task.Supervisor` limits concurrent runs. If Firecrawl rate-limits, the tool returns `{:error, reason}` and the LLM decides how to proceed.

5. **DB polling from MCP**: Synchronous MCP clients must poll `get_agent_session`. A future improvement could push updates over a long-lived connection or expose a webhook parameter on `start_agent`.

6. **Shared PubSub topic**: We broadcast on both `agents:#{session_id}` and `agents:all`. The LiveView subscribes to both.
